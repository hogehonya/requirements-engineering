# 文献と適用の根拠

以下は関連分野の入口です。本スキルの4軸は運用上の独自整理であり、標準のチェックリストの転載ではありません。書籍全文や規格本文を読んだ結果を示すものでもありません。

| 資料 | 参照する場面・確認範囲 |
| :--- | :--- |
| [Software Requirements, Third Edition（出版元・目次）](https://www.microsoftpressstore.com/store/software-requirements-9780735679665) | 業務要求、文書化、検証、変更管理、追跡の範囲を確認する。第5、10、11、17、28、29章が入口。 |
| [IPA ユーザのための要件定義ガイド 第2版](https://www.ipa.go.jp/archive/digital/iot-en-ci/jyouryuu/youkenteigi20190912.html) | 業務側と開発側の要件定義・合意形成の入口。翻訳原著は未確認。 |
| [NASA Systems Engineering Handbook 4.0](https://www.nasa.gov/reference/4-0-system-design-processes/) | 関係者の期待、技術要求、論理的分解、設計解を反復して整合させる関係を確認する。「4.0」は章の番号であり、版番号ではない。 |
| [INCOSE Handbook 第5版案内](https://www.incose.org/resource/incose-systems-engineering-handbook-fifth-edition-updating-the-reference-for-practitioners/) | 公開イベント情報と概要にある目的を確認する入口。動画は会員限定で、ハンドブック本文は確認していない。 |
| [REBOK開発者論文の書誌・抄録](https://www.jstage.jst.go.jp/article/jissj/6/1/6_51/_article/-char/ja/) | 書誌情報と公開抄録から、国内編纂の知識体系の範囲と成立経緯を確認する。論文本文の精読結果ではなく、単一英語原著の翻訳とも扱わない。 |
| [ISO/IEC/IEEE 29148:2018](https://www.iso.org/standard/72089.html)、[ISO/IEC/IEEE 15288:2023](https://www.iso.org/standard/81702.html) | 要求工学・ライフサイクルの公式公開概要のみを参照する。規格本文未読のため準拠・認証を断定しない。 |

対象案件で文献の具体的な主張に依拠する場合は該当箇所を読み、資料名・版・箇所と実際の確認範囲を示します。文献の推奨とユーザーの決定は区別します。
